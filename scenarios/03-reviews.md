# Кейс 3. Отзывы на продавца

После сделки покупатель оставляет продавцу отзыв с оценкой. Отзывы видны всем,
из них складывается рейтинг продавца.

Сущность Review:
- id (integer)
- sellerId (integer) - кому отзыв
- rating (integer) - оценка 1-5
- text (string)

## Чекпоинт 1 (руками в main.go)
GET /reviews/{id} - вернуть JSON отзыва: id из пути, остальное любое.

## Чекпоинт 2 (через спеку)
POST /reviews - тело с sellerId, rating и text, ответ 201 с созданным Review.
Схемы Review и ReviewCreate опишите в components по образцу Item/ItemCreate.

## Чекпоинт 3 (раскладка ручек, без кода)
Операции: оставить отзыв, посмотреть один, список отзывов продавца
(с фильтром по оценке), удалить свой отзыв.
Для каждой: метод + путь + статус ответа.
