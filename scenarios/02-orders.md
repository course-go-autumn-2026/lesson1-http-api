# Кейс 2. Заказы доставки

Авито Доставка: покупатель оформляет заказ на товар, следит за статусом
и может отменить, пока заказ не уехал.

Сущность Order:
- id (integer)
- itemTitle (string) - что везем
- address (string) - куда
- status (string) - created / shipped / cancelled

## Чекпоинт 1 (руками в main.go)
GET /orders/{id} - вернуть JSON заказа: id из пути, остальное любое.

## Чекпоинт 2 (через спеку)
POST /orders - тело с itemTitle и address, ответ 201 с созданным Order
(status - created). Схемы Order и OrderCreate опишите в components
по образцу Item/ItemCreate.

## Чекпоинт 3 (раскладка ручек, без кода)
Операции: оформить заказ, посмотреть один, список своих заказов, отменить заказ.
Для каждой: метод + путь + статус ответа.

Спорный вопрос к финалу: пользователь нажал «отменить» дважды (сеть моргнула,
запрос ушел повторно) - что вернуть на вторую отмену: 200, 409 или что-то еще?
