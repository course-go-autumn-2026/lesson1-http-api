# Кейс 1. Объявления

Вы делаете сердце Авито - сервис объявлений. Продавец размещает объявление,
покупатели его смотрят, продавец может снять его с публикации.

Сущность Listing:
- id (integer)
- title (string) - заголовок
- price (integer) - цена в рублях
- status (string) - active / hidden

## Чекпоинт 1 (руками в main.go)
GET /listings/{id} - вернуть JSON объявления: id из пути, title и price любые.

## Чекпоинт 2 (через спеку)
POST /listings - тело с title и price, ответ 201 с созданным Listing
(status ставьте active). Схемы Listing и ListingCreate опишите в components
по образцу Item/ItemCreate.

## Чекпоинт 3 (раскладка ручек, без кода)
Операции: создать, посмотреть одно, список активных, скрыть объявление.
Для каждой: метод + путь + статус ответа.

Спорный вопрос к финалу: скрыть - это DELETE или PATCH со статусом?
И что вернет список, если активных объявлений нет?
