# Сценарии для групп

Кейсы для финального обсуждения: проектирование раскладки ручек без кода.

Разбивка: группы по 4-5 человек, группа N берет сценарий N (шестая группа -
снова первый, и так далее). В карточке каждого кейса нужна только последняя
секция - «раскладка ручек». Если один кейс достался двум группам - отлично,
сравним их раскладки.

- 01 - Объявления
- 02 - Заказы доставки
- 03 - Отзывы на продавца
- 04 - Запись к мастеру
- 05 - Избранное

В финале пары 2-3 группы показывают свою раскладку ручек из чекпоинта 3 -
у каждого кейса там спрятан свой спорный вопрос, его и обсудим.
