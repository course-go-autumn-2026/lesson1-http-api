# Кейс 5. Избранное

Сердечко на объявлении: пользователь собирает понравившиеся объявления,
смотрит их списком и убирает лишнее.

Сущность Favorite:
- id (integer)
- itemId (integer) - какое объявление
- title (string) - заголовок объявления
- category (string) - например electronics / services

## Чекпоинт 1 (руками в main.go)
GET /favorites/{id} - вернуть JSON записи избранного: id из пути, остальное любое.

## Чекпоинт 2 (через спеку)
POST /favorites - тело с itemId, title и category, ответ 201 с созданным
Favorite. Схемы Favorite и FavoriteCreate опишите в components
по образцу Item/ItemCreate.

## Чекпоинт 3 (раскладка ручек, без кода)
Операции: добавить в избранное, посмотреть запись, список избранного
с фильтром по категории, убрать из избранного.
Для каждой: метод + путь + статус ответа.

Спорный вопрос к финалу: пользователь дважды жмет сердечко на одном
объявлении - второй POST вернет 409 или тихо 200? А DELETE того,
чего в избранном нет - 404 или 204? (загуглите слово «идемпотентность»)
