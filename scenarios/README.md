# Сценарии для групп

Пять кейсов - одна механика. Шаги и чекпоинты у всех одинаковые (см. корневой README),
отличается только предметная область: своя сущность, свои поля, своя раскладка ручек.

Разбивка: группы по 4-5 человек, группа N берет сценарий N (шестая группа -
снова первый, и так далее). Один код на группу: драйвер шарит экран и печатает,
меняется на каждом чекпоинте. Если один кейс достался двум группам - отлично,
в финале сравним их раскладки.

- 01 - Объявления
- 02 - Заказы доставки
- 03 - Отзывы на продавца
- 04 - Запись к мастеру
- 05 - Избранное

В финале пары 2-3 группы показывают свою раскладку ручек из чекпоинта 3 -
у каждого кейса там спрятан свой спорный вопрос, его и обсудим.
