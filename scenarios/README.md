# Сценарии для групп

Пять кейсов - одна механика. Шаги и чекпоинты у всех одинаковые (см. корневой README),
отличается только предметная область: своя сущность, свои поля, своя раскладка ручек.

Разбивка: группы по 5 человек, группа N берет сценарий N (шестая группа - снова
первый сценарий, и так далее). Внутри группы каждый пишет код у себя,
обсуждаете и сверяетесь друг с другом.

- 01 - Объявления
- 02 - Заказы доставки
- 03 - Отзывы на продавца
- 04 - Запись к мастеру
- 05 - Избранное

В финале пары 2-3 группы показывают свою раскладку ручек из чекпоинта 3 -
у каждого кейса там спрятан свой спорный вопрос, его и обсудим.
